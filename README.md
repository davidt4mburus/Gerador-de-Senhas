GERADOR DE SENHAS EM PYTHON

Programa em Python que gera senhas aleatórias e seguras, a partir das preferências do usuário.

🎯 Objetivo

Projeto criado para praticar lógica de programação, manipulação de strings e uso dos módulos random e string do Python, aplicados a um problema prático e útil.

⚙️ Como funciona
O programa pergunta o nome do usuário.
Em seguida, pergunta quantos caracteres a senha deve ter (mínimo de 5).
São geradas 3 sugestões de senha, cada uma contendo obrigatoriamente:
pelo menos 1 letra maiúscula
pelo menos 1 letra minúscula
pelo menos 1 número
pelo menos 1 caractere especial
Ao final, o usuário pode escolher gerar mais 3 senhas ou encerrar o programa.
🧠 Conceitos praticados
Entrada e validação de dados (input, laço de validação)
Módulo string (conjuntos prontos de letras, números e símbolos)
Módulo random (random.choice, random.shuffle)
Estruturas de repetição (for, while)
Concatenação e embaralhamento de caracteres
🚀 Como executar

```bash python gerador_senhas.py ```
